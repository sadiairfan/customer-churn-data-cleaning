# Customer Churn - Data Cleaning & EDA (Task 1)

## 📌 Project Overview
This repository contains the implementation of **Task 1** of my Machine Learning internship at **TEYZIX CORE**. The main objective of this task was to perform rigorous data cleaning and exploratory data analysis (EDA) on a customer churn dataset to prepare it for predictive modeling.

## 🛠️ Key Steps Implemented
- **Data Inspection:** Analyzed dataset dimensions, data types, and structural issues.
- **Data Cleaning:** Handled missing values, identified and removed duplicate records, and corrected inconsistent data types.
- **Exploratory Data Analysis (EDA):** Investigated the distribution of key features and analyzed factors contributing to customer churn.

## 💻 Tech Stack
- **Language:** Python
- **Libraries:** Project built using Pandas, NumPy, Matplotlib, and Seaborn.
- **Environment:** Jupyter Notebook
